# Owner-supplied project photos

Photos from mall and building owners, used with their written permission.

1. Put the files in a folder named after the project's `slug` (see `src/data/locations/projects.json`),
   e.g. `public/images/locations/projects/siam-paragon/cover.webp`. WebP or JPG, max 1600 px wide.
2. Add an entry to `src/data/locations/owner-photos.json` keyed by the same slug: owner name,
   where the permission is recorded (email, date, person), and the photo list in display order.
   The first photo is the cover.
3. On the map these replace the Wikimedia Commons photos and are credited "Photo courtesy of <owner>".

Do not add photos here without written permission on file.
