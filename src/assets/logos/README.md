# Brand logos for the Operators Map

Drop a file here named after the brand or group id in `src/data/operators-map.ts`,
e.g. `mk-restaurants.svg`, `crg.png`, `suki-teenoi.webp`. Supported: svg, png, webp, jpg.

The card picks it up on the next build; until then it shows a monogram.
Prefer SVG, or PNG/WebP at least 256px on the short side with a transparent background.
