# Property image credits (batch 3 — spotlight slideshow)

All photos sourced from Wikimedia Commons. Each file's license was verified
from its Commons `extmetadata` at download time (2026-09-19). Each image was
cropped/resized to 1600×900 (cover) and re-encoded as WebP q76, which makes
these adaptations: CC BY-SA files must keep the same license for the adapted
image; CC BY and CC BY 2.0 require attribution; CC0 requires nothing.
No NC or ND licenses are used.
